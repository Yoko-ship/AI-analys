# Видеостудия UZStock

Откройте **Администрирование → ИИ-маркетинг → Видеостудия**, опишите ролик и
нажмите **Создать видео**. Например: «Покажи, как найти новости на UZStock, и
пригласи зрителя на сайт». Канал, рекламная кампания и расписание не нужны.

Агент на сервере использует существующее подключение модели (Codex по умолчанию:
gpt-6.1-terra, medium). Он готовит русский PR-сценарий из 3–6 сцен, опираясь на
доступные разделы сайта. Сценарий сохраняется в карточке проекта.

Подключённый ПК озвучивает сцены сохранённым голосом `uzstock-male-v1` через
локальную Qwen Base, записывает публичные страницы UZStock и собирает видео.
Субтитры разбиты на короткие фразы; тайминг фраз приблизительный, по длине текста.
Экспорт: MP4, H.264, 1080×1920, 30 кадров/с, AAC 48 кГц. Файл проверяется на
сервере и становится доступен через **Посмотреть видео** и **Скачать MP4**.
Перед публикацией прослушайте произношение и посмотрите результат.

ПК должен быть включён, с активным пользователем Windows и работающим
видеоворкером. Если он выключен, сценарий остаётся на сервере и ждёт подключения.
Кнопки **Отменить** и **Повторить** управляют отдельным видеопроектом.
Загрузка файла не создаёт и не публикует посты в Telegram или других соцсетях.

## Однократная установка ПК

Нужны Python-окружение проекта, Node с Playwright/Chromium, FFmpeg/FFprobe,
локальная Qwen Base с CUDA и проверенный сохранённый voice prompt.
Приватный JSON-конфиг вне git содержит `server`, `token`, `qwen_python`,
`qwen_model`, `voice_directory`, `output_directory`. Токен совпадает с
`MARKETING_VIDEO_WORKER_TOKEN` сервера и даёт доступ только к очереди видео.
Он не является администраторским логином. CI переносит GitHub secret с тем же
именем в приватный серверный `.env`; публичный интерфейс никогда его не возвращает.

Запуск: `python -m video_worker.worker --config <private-config.json>`.
`scripts/install_video_worker.ps1 -ConfigPath <private-config.json>` запускает
процесс в фоне и добавляет ярлык в автозагрузку текущего пользователя Windows.
Журнал `worker.log` находится рядом с конфигом. Сценарии, голос, исходные записи
сайта, субтитры и MP4 сохраняются в `output_directory` для дальнейшего монтажа.
Чтобы отключить автозапуск, удалите ярлык **UZStock Video Worker** из автозагрузки.

Воркеры получают отдельную аренду задания. Просроченный воркер не может заменить
результат новой попытки. MP4 загружается частями по 512 КБ с проверкой смещения,
чтобы не зависеть от лимита больших запросов у внешнего прокси.
