# Automated review of Telegram pull requests

The Telegram watcher opens a draft. A separate reviewer examines the patch
after GitHub Actions tests the proposed merge with the current API branch.
A conflict, missing or failed CI job, or blocking finding leaves the change
outside the release branch.

Financial changes need evidence for the issuer, period, share class and
units. When a source value cannot be verified, keep the metric blank.
A passing review is specific to the tested revision. A new commit or an
updated API branch requires fresh checks.
